- Save Message As (File, or a message's right-click menu) saves the message as it was received, byte for byte, so that a Digital signature still checks in the file: for mail of a Microsoft, Exchange server or JMAP account it downloads the server's own copy first, and a signed or encrypted message is saved from the bytes it came as. A message that can't be had that way is saved from what this computer keeps, and the status bar says so; one of which only the headers are here is no longer saved as if it were whole ([#1561](https://github.com/GITHUB_REPOSITORY/issues/1561)).
