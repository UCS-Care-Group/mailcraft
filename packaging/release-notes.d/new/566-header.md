- **Rules: words in the message header.** A rule can now look for words in a message's header (Header contains), as a condition or as an exception; on a Microsoft account the rule is kept on the server. For mail that arrived before such a rule existed, MailCraft has only part of the header, so an exception whose word it doesn't find there leaves that mail alone. MailCraft 0.15.0 and earlier can't open a mailbox that holds such a rule ([#566](https://github.com/GITHUB_REPOSITORY/issues/566)).
