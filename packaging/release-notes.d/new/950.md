- Send later (#950, #1363): Delay Delivery in the Message tab, and Send Later… beside the Send button, hold a message in the Outbox until a date and time you choose. It waits there, where you can change its time or cancel it (it goes back to Drafts), it survives closing MailCraft, and if MailCraft wasn't running at that time it goes at the next run and the status bar says it is late. A Microsoft account's delayed message is kept and sent by MailCraft, not held by the server. The status bar shows when the next one goes.
- Undo Send (#950): File › Options › Wait before sending (off; 5 to 30 seconds) keeps each message in the Outbox for that long after Send, with "Sending in N s · Undo" across the window; Undo, or Ctrl+Z while it shows, puts the message back in a window to write again.
