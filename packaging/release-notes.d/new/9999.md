- Automatic Replies for IMAP accounts whose server keeps Sieve scripts (ManageSieve: Dovecot, Cyrus, Stalwart and many hosters) ([#9999](https://github.com/GITHUB_REPOSITORY/issues/9999)). File › Info › Automatic Replies turns them on or off, with a reply inside your organisation (your address's domain) and one outside, and a time range where the server can test dates. They are kept in a script of MailCraft's own, `mailcraft`, so they go out while MailCraft is closed. MailCraft never writes over a script it didn't write and never switches off a script of yours: a script changed elsewhere is left alone until you choose Replace with MailCraft's. The Sieve server is the IMAP server on port 4190 with STARTTLS, or the one you name in Account Settings. When the Sieve server can't be had, File › Info, the dialog and Rules and Alerts say what was found there, naming the host and port: nothing answers; it says nothing (a port that expects encryption from the start, as Dovecot's `ssl = yes` on the sieve listener, which ManageSieve doesn't use, is named as such); something else answers; no STARTTLS (MailCraft then doesn't sign in); or the secure connection failed. Try again asks once more.
