- Picture size ([#1310](https://github.com/GITHUB_REPOSITORY/issues/1310)): resize a picture you pasted or inserted into a message: click it and drag its bottom-right corner, or type its width or height in pixels in the Picture size strip that appears along the foot of the message (Reset Size gives it its own size again). The height keeps its proportions, recipients see the new size, and Ctrl+Z puts the old size back.
