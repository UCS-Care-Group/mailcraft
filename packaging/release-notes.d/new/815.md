- **Import a .pst file (preview).** File › Open & Export › Import a .pst File brings the mail of a .pst file into a new folder on this computer named after the file, or under a folder on this computer you pick; a file with a password asks for it. Mail only for now: calendar items, contacts, tasks and notes are counted and left for a later version. You see what came in, what was already there and what was left out, and a report is written beside your mailbox. Cancel keeps what came in, and importing the file again brings only the rest. Not in the browser yet ([#815](https://github.com/GITHUB_REPOSITORY/issues/815)).
