- **Import a .pst file (preview).** File › Open & Export › Import a .pst File brings the mail and the contacts of a .pst file onto this computer. Mail goes into a new folder named after the file, or under a folder on this computer you pick; contacts go into your contacts, each marked "Imported from" the file (and found by searching `is:imported`), and a distribution list becomes a contact whose notes list its members. Contacts in Deleted Items are left out. A file with a password asks for it. Calendar items, tasks and notes are counted and left for a later version. You see what came in, what was already there and what was left out, and a report is written beside your mailbox. Cancel keeps what came in, and importing the file again brings only the rest. Not in the browser yet ([#815](https://github.com/GITHUB_REPOSITORY/issues/815)).
