- **Write more than one message at once.** New Email, Reply, Reply All, Forward and opening a draft no longer ask you to save or discard the message you are writing: the new one opens in a window of its own, and the one you were writing stays open, saved to Drafts first so nothing of it is lost. Each message keeps its own undo. Quitting, or opening another mailbox, asks once about every message with changes. An agent writing for you names the message it means, and never writes in yours ([#286](https://github.com/UCS-Care-Group/mailcraft/issues/286)).
