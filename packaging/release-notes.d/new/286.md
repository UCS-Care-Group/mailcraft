- **Write more than one message at once, each in a window of its own.** A draft you double-click opens in a window of its own, with its own Message, Insert, Format Text and Review tabs, and so does a reply or forward you start in a message's window. New Email (Ctrl+N) and a reply or forward started in the main window start in the reading pane: Pop Out, at its top right, moves the message into a window, and File › Options › Mail › Open new messages, replies and forwards in a new window opens them there from the start. Starting another message no longer asks about the one you are writing: it stays open, saved to Drafts first so nothing of it is lost, and each message keeps its own undo. Closing a message's window with changes asks Save, Don't Save or Cancel; closing MailCraft saves every message being written to Drafts without asking; opening another mailbox asks once about every message with changes. Up to 12 windows of their own are open at a time. A message an agent writes for you opens in a window behind yours, without taking the keyboard, and the agent never writes in yours. Each kind of window (a message, a message being written, an appointment) opens where the last one of its kind was, at its size, a step down and to the right of one still open, and on the main monitor when its own is no longer connected. Every message you are writing with changes is saved to Drafts every five minutes, whatever kind of account it is from, not only a Microsoft account's; closing a new message that only these saves put in Drafts asks first, and Don't Save takes it out again ([#286](https://github.com/UCS-Care-Group/mailcraft/issues/286)).
