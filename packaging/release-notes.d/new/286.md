- **Write more than one message at once, each in a window of its own.** New Email (Ctrl+N) opens the message in a window of its own, with its own Message, Insert, Format Text and Review tabs; so do a draft you double-click and a reply or forward you start in a message's window. A reply or forward started in the main window starts in the reading pane: Pop Out, at its top right, moves it into a window, and File › Options › Mail › Open replies and forwards in a new window opens them there from the start. Starting another message no longer asks about the one you are writing: it stays open, saved to Drafts first so nothing of it is lost, and each message keeps its own undo. Closing a message's window with changes asks Save, Don't Save or Cancel; closing MailCraft saves every message being written to Drafts without asking; opening another mailbox asks once about every message with changes. Up to 12 windows of their own are open at a time. A message an agent writes for you opens in a window behind yours, without taking the keyboard, and the agent never writes in yours ([#286](https://github.com/UCS-Care-Group/mailcraft/issues/286)).
