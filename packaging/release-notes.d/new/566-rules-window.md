- **The Rules window, laid out as Outlook's.** The Rules window has a search by name and New Rule over the rules; each rule has its switch, says where it is kept, has arrows to move it up or down and a menu with Run Rule Now, Keep Rule on Server and Delete Rule, and opens to show what it does. New Rule opens the new rule on a page in the list's place, with Add Rule and Cancel. Every rule moves up and down with its arrows, one the server doesn't let be changed too: if the server won't have the move, MailCraft says so and the rule goes back to its place. A rule still to go to the server moves once it is there, and its arrows say so. The window can be moved and resized, and keeps its size ([#566](https://github.com/GITHUB_REPOSITORY/issues/566)).
