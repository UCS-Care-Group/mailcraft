- **Snooze, first part.** Mail can be snoozed by command (`mail.snooze` with a Return time, `mail.unsnooze` for Return now, `mail.returnDue` for the return step): the message waits in a Snoozed folder on its account's server, or on this computer, and comes back at its Return time to the folder it came from, unread. A new message in the same conversation brings it back at once, and one moved out of the Snoozed folder by hand is not brought back later. The Return time stays on this computer. The window's Snooze button and menu follow in the next release ([#949](https://github.com/GITHUB_REPOSITORY/issues/949)).
