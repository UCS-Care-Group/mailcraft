- [#544](https://github.com/UCS-Care-Group/mailcraft/issues/544): File › Options › General has Close to system tray, off by default. While enabled, MailCraft’s icon offers Show, Send/Receive All Folders and Quit. The first close explains where the icon is, including Windows’ hidden-icons arrow; on macOS, clicking the Dock icon restores the window too. Quit saves and protects unsaved work. On Wayland, restart after enabling: MailCraft chooses X11/XWayland only if reachable; without a working tray or window hiding, closing exits normally.
