- **All Inboxes.** With two of your own mailboxes or more, File › Options › Mail can show a row above Favorites that lists every Inbox together, with the unread count. A shared mailbox is not in that list. The switch is off until you turn it on. Mark All as Read and Run Rules Now cover each of those Inboxes. Right-click Hide All Inboxes turns the row off. A search of Current Folder, Subfolders or Current Mailbox looks through every one of those Inboxes, and the bar says so. [#625](https://github.com/UCS-Care-Group/mailcraft/issues/625)
