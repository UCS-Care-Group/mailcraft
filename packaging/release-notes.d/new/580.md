- Left, centre and right alignment of a paragraph in a message and in a signature, kept when sent, on a paste and in a draft; a list item stays left; for scripts and agents it is the command `format.align` ([#580](https://github.com/GITHUB_REPOSITORY/issues/580)).
- Align Left, Center and Align Right in the Message tab and the Format Text tab, and Ctrl+L, Ctrl+E and Ctrl+R while you type in a message or a signature (there Ctrl+R no longer replies and Ctrl+E no longer goes to the search); the line is shown aligned as it will be sent, pictures included ([#580](https://github.com/GITHUB_REPOSITORY/issues/580)).
- File › Signatures formats a signature with the Message tab's Basic Text buttons: bullets, numbering, indent, alignment, highlight and Clear All Formatting beside the font, size, colour, bold, italic, underline and link it had, and typing goes on in the signature after a click on any of them ([#580](https://github.com/GITHUB_REPOSITORY/issues/580)).
