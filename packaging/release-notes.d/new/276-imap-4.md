- New mail on a mail-server (IMAP) account shows within moments when the server supports IDLE: MailCraft keeps one extra connection to your own mail server open on the Inbox while automatic Send/Receive is on, and runs a quick Send/Receive when the server says there is more mail. Turning automatic Send/Receive off, working offline or removing the account closes it. Servers without IDLE keep to the timer. (#276)
