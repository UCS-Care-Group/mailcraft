- **Account Problems.** When an account's sign-in runs out or its server turns the password down, Account Problems at the top right of the window lists it with **Sign in again**, and a mark beside the account in the folder pane says so too, until a sign-in goes through. It stays after a restart, and nothing pops up by itself. The mailbox file keeps it, so a copy made with **Save Mailbox As**, or the file opened on another computer, says it too until a Send/Receive there goes through ([#1556](https://github.com/GITHUB_REPOSITORY/issues/1556)).
