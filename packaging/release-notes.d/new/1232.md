- **Files inside `winmail.dat`.** Mail sent from Outlook in its own rich-text format carries its files wrapped in one `winmail.dat` attachment; MailCraft now lists the files inside it (with their names and types) beside it, and uses its text as the message's when the message has none of its own. Nothing in it runs or is fetched, and an attached message or object inside it stays in the `winmail.dat`. Mail already in a mailbox is unchanged until it is downloaded again ([#1232](https://github.com/GITHUB_REPOSITORY/issues/1232)).
