- Longer Undo Send ([#1799](https://github.com/GITHUB_REPOSITORY/issues/1799)): File › Options › Wait before sending now also offers 1 minute and 2 minutes. After Send the message waits in the Outbox for that long, with Undo on the bar across the window, which brings it back to write again as it was. If MailCraft is closed during the wait, the message stays in the Outbox and goes when MailCraft next runs (Cancel Send still takes it back); while working offline it waits until you are online again. Recalling a message that has already gone is not part of this.
