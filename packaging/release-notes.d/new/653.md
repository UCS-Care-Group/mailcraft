- **Mail to keep offline for IMAP accounts.** Gmail and other IMAP accounts now have the Mail to keep offline slider in File › Info and Account Settings, as Microsoft accounts do. Older mail is kept as its headers and a preview, and downloads from the server when you open it, so a large mailbox takes far less space on this computer; the download itself changes nothing on the server (opening a message marks it as read as it always has, when File › Options says so). An account you already had keeps all its mail until you move the slider ([#653](https://github.com/GITHUB_REPOSITORY/issues/653)).
