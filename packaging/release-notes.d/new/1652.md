- **HTML signatures from a file, checked for other mail programs.** File › Signatures › Import HTML… makes a signature from an `.html` or `.htm` file (up to 64 KB), and asks for the file of each picture on this computer that it names (up to 256 KB each and 512 KB together), which then goes with your mail as an attached picture; a picture on the web keeps its address. In the signature's HTML, what other mail programs, classic Outlook for Windows above all, won't show as written is underlined. Pointing at it says why and, where one edit puts it right, offers that edit. A signature with something in it that would be lost (a picture written into the HTML, an SVG picture, a style rule that can't be sent, or a style with something in it that can't be sent safely, such as a background picture, which would leave out the whole style, its colours and spacing with it) can't be saved until that is fixed ([#1652](https://github.com/GITHUB_REPOSITORY/issues/1652)).
