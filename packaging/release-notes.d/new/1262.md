- Check Names (Ctrl+K) in a message from an Exchange server account also looks names up in your organisation's address list: one match is put in, and when several people match you choose one ([#1262](https://github.com/GITHUB_REPOSITORY/issues/1262)).
- People has an Address Book for an Exchange server account: choose "Address list" at the top of the list (or Home › Address Book) and type a name in the search box to search your organisation's address list; Email writes to whoever you pick, and Add to Contacts keeps a copy ([#1262](https://github.com/GITHUB_REPOSITORY/issues/1262)).
