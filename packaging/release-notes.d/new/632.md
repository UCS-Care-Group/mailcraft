- **Each account's tasks apart.** With a Microsoft account, Tasks has a list under My Tasks: All accounts, one account, or On this computer; with All accounts each task says where it is. A new task goes where you choose: the task window has an Account list, and the field above the tasks says where it will go (with All accounts, the last place you used). Add to Tasks puts the task in the message's account. *Send Your Local Tasks to To Do?* now asks only about the tasks already on this computer, and a task you choose to keep on this computer stays there ([#632](https://github.com/GITHUB_REPOSITORY/issues/632)).
