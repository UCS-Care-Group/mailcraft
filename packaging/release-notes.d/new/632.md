- **Each account's tasks apart.** With a Microsoft account, Tasks has a list under My Tasks: All accounts, one account, or On this computer; with All accounts each task says where it is. The task window has an Account list, and the field above the tasks says where a new task will go. New tasks that were waiting for an earlier answer go there once ([#632](https://github.com/GITHUB_REPOSITORY/issues/632)).
