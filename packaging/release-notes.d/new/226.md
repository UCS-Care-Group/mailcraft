- **JMAP accounts in the browser build.** The browser build can now read an account whose server speaks JMAP: Send/Receive lists the server's mailboxes and brings down the newest messages with their read, flagged and answered marks, and a message downloads whole when you open it. Nothing goes up to the server and nothing is sent from such an account yet. The server has to let the page in (CORS) and the account takes the address of the JMAP session itself; a site that serves MailCraft can name its users' accounts and hold their sign-in. How to add one is in [docs/jmap.md](https://github.com/GITHUB_REPOSITORY/blob/main/docs/jmap.md) ([#226](https://github.com/GITHUB_REPOSITORY/issues/226)).
