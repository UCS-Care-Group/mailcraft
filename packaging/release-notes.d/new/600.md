- **Mail in the fonts its sender chose.** A message written in a font you have installed (Georgia, say, or any other on your computer) is now shown in it instead of in MailCraft's own font. Of the fonts a message names, the first you have is used; one that asks for a serif font is shown in your computer's serif font and one that asks for a typewriter font in MailCraft's, and when you have none of them the message is shown as before. No font is ever downloaded: a message that brings its own fonts or asks for one from the web is shown in the fonts you already have. Bold text uses the font's bold face, or MailCraft's bold when the font has none. In the browser, MailCraft can't see your fonts and shows messages as before ([#600](https://github.com/GITHUB_REPOSITORY/issues/600)).
