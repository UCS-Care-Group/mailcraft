- Add Account finds an Exchange server from the address's domain: when a domain MailCraft doesn't know publishes Exchange's automatic setup (Autodiscover) in its DNS, you are asked whether it is an Exchange server (a hosted one or the organisation's own) or IMAP, since some hosting providers publish it for their IMAP mail too, and a domain whose automatic setup is Microsoft's goes to Microsoft 365 sign-in even when another server takes its mail in first. The search for the server also follows the domain's public `autodiscover.<domain>` alias to its hoster, so a domain whose SRV record is only in its own network's DNS is found too. Server settings show where automatic setup was found, with Search again. Only the domain is looked up, and nothing is sent to the servers named before you press Connect with your password and agree to each server outside your domain.
