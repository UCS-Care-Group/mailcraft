Linchange accounts: Add Account finds a Linchange server from the domain's mail exchangers and uses IMAP and SMTP for mail, with CalDAV for calendars (shared calendars too) and CardDAV for address books (shared books and the organization directory, each contact showing its book). The Linchange tile has its own icon. A Linchange account signs in through its server's own page in the browser and stores an application password named for this computer, so the account password and second factor never go to the mail client.
