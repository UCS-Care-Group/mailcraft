- **One MailCraft at a time, and MailCraft as your mail program.** Starting MailCraft while it is open, clicking a `mailto:` link or opening a file from the file manager brings the open window to the front instead of opening a second copy over the same mailbox. A `mailto:` link starts a new message with what the link says, a `.eml` file is kept in the folder Imported on this computer and opens in a window of its own (opened again, it is the same copy), and a `.ics` or `.vcf` file asks before its appointments or contacts are imported. On Windows and Linux MailCraft is offered for `mailto:` links and these files; it never makes itself the default, so choose it in the system's settings ([#505](https://github.com/GITHUB_REPOSITORY/issues/505)).
