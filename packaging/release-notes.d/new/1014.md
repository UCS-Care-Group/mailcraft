- **JMAP accounts in the desktop app.** An account on a JMAP server (RFC 8620/8621) now works in the desktop app as in the browser build: its mailboxes, the newest messages and their marks come down, messages are fetched whole when opened, the read marks, flags, moves and deletions you make go up, and mail is sent through the server. The password or token is asked for once per start and never stored; see docs/jmap.md ([#1014](https://github.com/GITHUB_REPOSITORY/issues/1014)).
