- Online archive for Exchange server accounts ([#1818](https://github.com/UCS-Care-Group/mailcraft/issues/1818)): when the server says an Exchange server account's mailbox has a personal archive, it appears in the folder pane as **Online Archive – address**, right after the mailbox. As in Outlook, it is read from the server while connected and nothing of it is kept on this computer: its folder list when it is opened, and a folder's mail when that folder is opened; offline it says it needs a connection. Mail in it is read, marked read or unread, flagged, categorised, replied to and forwarded, deleted into the archive's own Deleted Items, and moved; folders are made, renamed, moved and deleted there. Its right-click menu has Refresh and Hide Online Archive (`account.archive.hide`, `account.archive.show`). It isn't counted in the unread badge or new-mail alerts, and nothing of it goes anywhere but the account's own server. An archive kept in Microsoft 365 for a mailbox on the organisation's own server isn't shown, and MailCraft says so once.
