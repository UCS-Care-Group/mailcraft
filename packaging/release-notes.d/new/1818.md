- Online archive for Exchange server accounts ([#1818](https://github.com/GITHUB_REPOSITORY/issues/1818)): when the server says an Exchange server account's mailbox has a personal archive, it appears in the folder pane as **Online Archive – address**, right after the mailbox. As in Outlook, it is read from the server while connected and nothing of it is kept on this computer: its folder list when it is opened, and a folder's mail when that folder is opened; offline it says it needs a connection. Mail in it is read, marked read or unread, flagged, categorised, replied to and forwarded, deleted into the archive's own Deleted Items (on a server whose archive has no Deleted Items, a delete there is for good, after MailCraft asks), and moved; folders are made, renamed, moved and deleted there. Mail from other accounts or from this computer isn't moved or copied into it, as only the mailbox's server puts mail there; a move into it not yet made when it is hidden or MailCraft closes is called off, the message left where the server has it, and a read mark, flag or delete made in it that hasn't reached the server when MailCraft closes is dropped, the server keeping the message as it was. Its right-click menu has Refresh and Hide Online Archive (`account.archive.hide`, `account.archive.show`). It isn't counted in the unread badge or new-mail alerts, and nothing of it goes anywhere but the account's own server. An archive kept in Microsoft 365 for a mailbox on the organisation's own server isn't shown, and MailCraft says so once.
