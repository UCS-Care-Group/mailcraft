- Run Rules Now no longer judges a draft that was changed or sent on another device, or a message that is a draft again, by the version downloaded before, while its new version isn't downloaded yet: a rule for mail with an attachment or with words in the body could act on it for a file or words taken out there. No rule acts on such a message until its new version is downloaded; Run Rules Now then goes by that version ([#566](https://github.com/GITHUB_REPOSITORY/issues/566)).
