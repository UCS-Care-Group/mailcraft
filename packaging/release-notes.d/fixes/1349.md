- An Exchange 2010 server can be added and its mail read and marked: a server that doesn't know the version of Exchange Web Services asked for (`ErrorInvalidServerVersion`; Exchange 2010 knows none after `Exchange2010_SP2`) is asked again with the version before it, and the one it took is kept; a server whose folder changes don't give the preview, the flag or the recipients of a message (Exchange 2010 refuses them in `SyncFolderItems`) has its mail read without them and the recipients asked with `GetItem`; a server that takes no change without the item's change key (`ErrorChangeKeyRequiredForWriteOperations`) has it read first, so marking mail read, its categories and its importance go up; and a flag set on a server without flags stays on this computer instead of failing the change ([#1349](https://github.com/GITHUB_REPOSITORY/issues/1349)).
