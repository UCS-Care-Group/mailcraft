- An imported `.ics` file no longer hides in your Microsoft 365 calendar without reaching it: when the account's calendar was the only one, an imported appointment went into it as if it were there, was never sent, and nothing offered to send it. It now goes into the calendar **On this computer**, with the bar above the calendar and **Move to Calendar** in its menu offering to move it to your account's calendar; one that an earlier import left behind goes there at the next Send/Receive ([#1050](https://github.com/GITHUB_REPOSITORY/issues/1050)).
