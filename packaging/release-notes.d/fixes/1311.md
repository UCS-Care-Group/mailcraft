- When a virus scanner takes away part of a message as it is saved ([#1311](https://github.com/UCS-Care-Group/mailcraft/issues/1311)), the rest of the mailbox is still saved and mail can still be sent; that part shows as unavailable. Before, every save failed from then on.
- When a virus scanner such as Bitdefender refuses part of a message on Windows with "access denied" ([#1311](https://github.com/UCS-Care-Group/mailcraft/issues/1311)), MailCraft waits a few seconds in case it lets go, then saves the rest of the mailbox without that part, so mail can still be sent. Before, every save failed and nothing was sent.
