- A mailbox file of the older one-file form larger than 512 MB now opens (up to 4 GB) instead of starting an empty mailbox, and is written in the current form at the next save; a big file that is not a mailbox at all is now said to be that, not "larger than 512 MB" ([#649](https://github.com/GITHUB_REPOSITORY/issues/649)).
- Saving no longer writes a mailbox file that opening would refuse: a save or a copy that would come to more than MailCraft opens is refused with a message, and the file stays as it was ([#649](https://github.com/GITHUB_REPOSITORY/issues/649)).
