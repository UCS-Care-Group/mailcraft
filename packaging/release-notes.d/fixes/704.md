- A message from another account or from this computer, moved or copied into an IMAP account's Outbox and sent with Send Again, is filed in Sent Items once: the next Send/Receive no longer also puts it on the server as a message moved in. Mail moved into a Microsoft account that its server doesn't have yet can't go on into that account's Outbox, and a copy can't go into a Microsoft or Exchange server account's Outbox, where the next Send/Receive would have sent it without Send ([#704](https://github.com/GITHUB_REPOSITORY/issues/704)).
