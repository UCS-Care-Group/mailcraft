- A message copied to another folder of a Microsoft or Exchange server account, or into another account, and then deleted permanently, by you or by a rule, is no longer lost when the server refuses the copy or says there is no such message: the original is deleted from its server only once the copy is there, and a refused copy brings it back where it was, with its text and files (a message that was only on this computer, has nowhere to come back to, or that the server says isn't there, deleted on your phone say, has its copy kept there instead, in Imported), and a copy you move onto this computer or into another account before the server answers stays where you put it instead of being taken away ([#566](https://github.com/GITHUB_REPOSITORY/issues/566)).
