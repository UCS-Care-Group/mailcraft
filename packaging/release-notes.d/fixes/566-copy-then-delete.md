- A message copied to another folder of a Microsoft or Exchange server account, or into another account, and then deleted permanently, by you or by a rule, is no longer lost when the server refuses the copy: the original is deleted from its server only once the copy is there, and a refused copy brings it back where it was, with its text and files (a message that was only on this computer, or has nowhere to come back to, has its copy kept there instead, in Imported) ([#566](https://github.com/GITHUB_REPOSITORY/issues/566)).
