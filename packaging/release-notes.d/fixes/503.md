- The Delete key, Archive, Move and dragging on a selected conversation's row now take every message the row shows, as the row's own delete button does; before, they took only the newest one ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- A conversation's row selected in the Unread tab now stays selected in the All tab; before, it lost its highlight there and Delete took one of its messages that the list didn't show ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- Keys pressed while an agent's question is on screen no longer reach the message list under it; before, Delete there moved the selected message to Deleted Items ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- An agent's question that is still on screen when another mailbox is opened now goes with the mailbox it was about; before, a yes could delete or send messages of the mailbox opened since ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
