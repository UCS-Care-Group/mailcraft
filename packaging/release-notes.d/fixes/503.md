- The Delete key, Archive, Move and dragging on a selected conversation's row now take every message the row shows, as the row's own delete button does; before, they took only the newest one ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- A conversation's row selected in the Unread tab now stays selected in the All tab; before, it lost its highlight there and Delete took one of its messages with nothing drawn selected ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- Keys pressed while an agent's question is on screen no longer reach the message list under it; before, Delete there moved the selected message to Deleted Items ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- An agent's question that is still on screen when another mailbox is opened now goes with the mailbox it was about; before, a yes could delete or send messages of the mailbox opened since ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- An agent's Delete or Move that names a message that isn't in the mailbox is now refused instead of asked about; before, if Undo put that message back while the question was on screen, a yes deleted it for good or moved it to the Outbox ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
- A conversation in the reading pane no longer counts its messages in folders under Deleted Items and Junk E-mail, such as those of a deleted folder ([#503](https://github.com/GITHUB_REPOSITORY/issues/503)).
