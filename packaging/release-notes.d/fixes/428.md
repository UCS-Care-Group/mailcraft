- In the Unread tab and in a search, a message you open stays in the list until you select another one or go to another tab or search, and Down goes to the next message. In the Flagged tab, a message whose flag you clear stays the same way. Messages you select together with Ctrl or Shift all stay the same way. Before, an opened message left the list at once, and Down went back to the first message ([#428](https://github.com/GITHUB_REPOSITORY/issues/428)).
- In a filtered tab or a search, the message you opened is still shown when you Ctrl+click another one and press Delete, as long as you stay in that tab or search. Before, it had left the list but stayed selected, so Delete removed a message you couldn't see ([#428](https://github.com/GITHUB_REPOSITORY/issues/428)).
- In a filtered tab or a search, Shift+click selects the messages from the one you opened in that list to the one you click, as long as you stay in that tab or search. Before, the opened message had left the list, and Shift+click selected nothing more ([#428](https://github.com/GITHUB_REPOSITORY/issues/428)).
