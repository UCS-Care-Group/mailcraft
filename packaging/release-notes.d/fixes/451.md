- A message you move from an IMAP account, such as Gmail, to a folder on this computer now leaves the IMAP server too, once it is fully downloaded and saved here. Before, it stayed on the server, so the move was only a copy. A message of which only the headers are here stays on the server ([#451](https://github.com/GITHUB_REPOSITORY/issues/451)).
- A message you move from your Microsoft account to a folder on this computer and back again while Send/Receive is removing it from Microsoft's server is no longer lost: it is put on the server again ([#451](https://github.com/GITHUB_REPOSITORY/issues/451)).
