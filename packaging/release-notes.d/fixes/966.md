- An Exchange server account no longer downloads every message in full: like a Microsoft account, it keeps mail in full only within its Mail to keep offline (12 months unless you change it in File › Info or Account Settings), and older mail as headers and a preview that download when you open them. "Messages to download per folder" in File › Options is for IMAP accounts ([#966](https://github.com/GITHUB_REPOSITORY/issues/966)).
