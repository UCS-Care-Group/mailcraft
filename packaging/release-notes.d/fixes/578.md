- A message you move from an IMAP account, such as Gmail, to a folder on this computer now leaves the IMAP server too, once it is fully downloaded and saved here. This goes for mail a rule files into a folder on this computer or another account too. Before, it stayed on the server, so the move was only a copy. A message of which only the headers are here stays on the server ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
- A message you move from your Microsoft account to a folder on this computer and back again, or whose move you undo, while Send/Receive is removing it from Microsoft's server is no longer lost: it is put on the server again, or, when that run's answer was lost, kept on this computer, in Imported ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
- A message whose text or one of whose attachments couldn't be read on this computer (its file missing or damaged), moved from your Microsoft account to a folder on this computer, no longer has its copy on Microsoft's server removed: that copy is all there is of it ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
- A message you move or copy between your Microsoft mailbox and a shared mailbox no longer names, in the copy, who got a blind copy (Bcc), which anyone who can open that mailbox could see ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
- A message you move into another folder and then delete for good with that folder, before Send/Receive, is now deleted from the server too. Before, it stayed in its first folder on the server and was shown nowhere ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
- A message that was resent with a blind copy no longer names who got that blind copy (Resent-Bcc) in what you send or export, or in a copy put on another server ([#578](https://github.com/GITHUB_REPOSITORY/issues/578)).
