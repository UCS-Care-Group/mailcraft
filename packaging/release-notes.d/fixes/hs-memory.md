- A large mailbox takes far less memory and disk: the header lines of a message that nothing in MailCraft reads by name (the trace, spam filters' reports and signatures Microsoft 365 writes on every message, often several kilobytes) are kept beside the mailbox file and read only by View Source and what writes a message whole. On a copy of one real mailbox of 66,000 messages, the mailbox file went from 738 MB to 208 MB, the memory held after opening from 1.45 GB to 0.6 GB, and opening from 2.8 s to 0.8 s. The first time this version opens your mailbox it writes the mailbox file anew and keeps the old one beside it as `<file>.before-<version>`, as large as the old file was (hundreds of megabytes for a large mailbox); earlier versions of MailCraft don't open the new file, only that kept one. Once this version has opened your mail and you don't mean to go back to an earlier one, the kept file can be deleted.
