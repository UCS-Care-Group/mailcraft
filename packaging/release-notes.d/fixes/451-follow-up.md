- A message moved into an IMAP account's Outbox can be moved or copied into another account, where it used to be refused as a draft. If that account refuses a message that left an Outbox, even one queued with Send, it is no longer sent: it goes back to its original or, if no server has one, into its Outbox, held until Send Again. An agent's question about an IMAP account's Outbox now says that the mail is held there, names that account and says whether it's a move or a copy; its question about an import no longer says mail is sent. A message no longer stays marked as held after its move into that Outbox is undone or its account is removed ([#451](https://github.com/GITHUB_REPOSITORY/issues/451)).
