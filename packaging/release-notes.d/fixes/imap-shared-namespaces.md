- On an IMAP server that shares other users' folders with the account (Dovecot's `shared/` namespace, or a public one), those folders now appear in the server's own tree under the account, `shared` ▸ the user ▸ their folders, instead of side by side at the top as "INBOX (2)", "Archiv (2)" and so on. Folders kept flat by an earlier version move into place, and get their own names back, at the next Send/Receive. Another user's INBOX, Sent, Drafts or Trash is never taken for the account's own, so sent copies, deleted mail and archived mail only go to the account's own folders.
