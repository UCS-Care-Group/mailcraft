- A reply or forward of an HTML message quotes only what the reading pane shows of it, in HTML and in plain text: however the message nests a template, a hidden block or an element that is left out whole, and as the message looked at the width and in the theme of the reading pane or window the reply was started from (a message not read there carries only what it shows at every width and in both themes). A message the pane shows as plain text is quoted as that text. Text after a template inside an SVG picture or a hidden block is shown again. Outlook's list markers are quoted as the pane shows them; a tooltip is no longer quoted, and the plain-text part of a quote no longer carries the alt text of a picture that is shown.
