- A reply or forward of an HTML message quotes only what the reading pane shows of it, in HTML and in plain text: however the message nests a template, a hidden block or an element that is left out whole, and as the message looked at the width and in the theme of the reading pane or window the reply was started from (a message not read there is quoted as the other places it was read in showed it, or with only what it shows at every width and in both themes). A message the pane shows as plain text is quoted as that text. Text after a template inside an SVG picture or a hidden block is shown again. Outlook's list markers are quoted as the pane shows them; a picture the pane doesn't draw is no longer quoted, nor a tooltip or the description of a picture in the message that is drawn. An appointment or task made from a message starts with the text the pane showed.
- A reply or forward, by an agent or from the message list, of a message never shown in the pane or a window, whose look at every width and theme can't all be worked out, carries the header of the original only.
