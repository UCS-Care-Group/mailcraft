| 2026-11-13 | #276 (part, IMAP 4): new mail the moment it arrives, on IMAP accounts whose server offers IDLE (RFC 2177). While the window is open and Send/Receive runs by itself, each such account has one extra connection to its own server, kept open in IDLE on the Inbox (examined read-only, signed in as Send/Receive is, with the password or token already in memory; the credential store is not read for it). When the server says the Inbox has more messages, the account's Send/Receive is queued quietly: it reads the Inbox first and passes over unchanged folders, so it is cheap. IDLE is renewed every 25 minutes; a dropped connection is made again after a wait doubling from 5 seconds to 5 minutes, at most 12 times an hour, after which the account is left alone for an hour; a server that can't do IDLE is left alone for a day, one that refuses the sign-in for ten minutes. A server that says more than 5,000 lines in one IDLE is left. Turning automatic Send/Receive off, working offline, removing the account or closing the mailbox stops the watch. The browser build has none. |
