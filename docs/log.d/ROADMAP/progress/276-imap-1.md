The statuses of all folders are asked in one pipelined go (50 to a write), so a 63-folder Gmail account spends a few round trips on them instead of two for every folder. A reading in full of every folder is due once an hour (a flag changed in another program that no count shows, such as Starred, waits for it), and a folder with messages waiting to be read again, a new numbering or a changed limit is always read. CONDSTORE (which would show flag changes at once) is not used yet. The Inbox is always read. |
