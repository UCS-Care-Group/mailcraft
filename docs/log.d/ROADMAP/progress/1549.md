| 2026-11-17 | #1549: an account's own fonts. File › Signatures has a Default fonts section under the default signatures: one row per account — a shared mailbox of its own — and a button for each of its three fonts, saying what is chosen or that the message's own stands. A button opens Outlook's Font dialog for that account and that font alone: a family, a style, a size, a colour, underline, and a sample drawn in what is chosen so far, with the family list the composer's (#1493) — the six MailCraft knows and the ones installed on this computer, searched the same way. What is chosen is what that account's mail is written in: a new message takes its font, a reply or forward the reply font, and a plain-text message the plain-text one, in the composer and in the reading pane, while a signature and the message being answered keep their own looks. A mailbox file that doesn't know the three reads without them, and one written by a newer MailCraft keeps what it holds. `signature.fonts` writes them, one step of undo, and `ui.dialog` name `font` opens the dialog.
