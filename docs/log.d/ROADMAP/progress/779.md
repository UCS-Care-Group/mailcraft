| 2026-11-05 | An Exchange server account's own folders are its server's ([#779](https://github.com/UCS-Care-Group/mailcraft/issues/779)), as #756 made them for a Microsoft account: Conversation History, Sync Issues, Conflicts, Local Failures and Server Failures are told apart by the ids the server gives for their distinguished names, asked for in one `GetFolder` of their own (in smaller groups when a server's schema lacks a name) that only a refused sign-in or a busy server lets end the run; the special folders and the server's Outbox are marked too. Delete, Move and Rename are greyed out for them, a change an earlier version left is never sent and is undone, and a folder deleted here that the server keeps is brought back by a read of the folder list afresh. Not tried against a live Exchange server yet. |
